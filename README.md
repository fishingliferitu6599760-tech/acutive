# Acutive｜顧客・売上・出金管理アプリ（初版 v1.0）

出張施術の副業で、顧客・売上・入金・経費・生活費への取り出し・副業資金の残高を、スマホで仕事の直後に記録するためのWebアプリです。

## 推奨構成

| 役割 | サービス | 置くもの |
|---|---|---|
| 画面の配信 | GitHub Pages | このリポジトリのHTML/CSS/JS（データは一切含まない） |
| ログイン | Supabase Auth（メール＋パスワード） | 本人のアカウント |
| データ保存 | Supabase（Postgres） | 顧客・売上・支出などの実データ（RLSで本人のみ読み書き） |

**選定理由**
- ビルド不要の静的ファイルなので、GitHub Pagesにそのまま置けて、修正も1ファイル単位で済む。
- Supabaseはデータベース側で「ログイン中の本人の行だけ読み書き可」を強制できる（Row Level Security）。画面を隠すだけの方式と違い、URLや公開鍵を知られてもデータは取れない。
- 公開してよい鍵（publishable key）と秘密鍵が分かれており、公開コードには前者だけを置ける。

**費用の目安（2026年11月時点・公式資料で確認）**
- Supabase Free：0円。DB 500MB／プロジェクト。1人分の記録なら十分。**ただし7日間ほとんど利用がないと一時停止**（ダッシュボードから再開可）。**自動バックアップなし**。
- Supabase Pro：25米ドル／月（停止なし・日次バックアップ7日分）。停止が困るようになったら移行を検討。
- GitHub Pages：公開リポジトリなら無料。非公開リポジトリで使うにはGitHub Pro等の有料プランが必要。
- 料金・条件は変わるため、契約前に https://supabase.com/pricing と GitHubの公式ドキュメントで再確認してください。為替による円換算額は未確定です。

## フォルダ構成

```
index.html            画面の入口
css/app.css           見た目（スマホ優先）
js/config.js          ★本番の接続設定（URLと公開鍵のみ）
js/util.js            日付（日本時間）・金額表示などの共通処理
js/calc.js            集計ロジック（画面・CSV・印刷すべてここを使う）
js/csv.js             CSV作成（Excel向け・数式インジェクション対策）
js/store/             データ層（supabase.js＝本番 / demo.js＝デモ）
js/views/             各画面
supabase/schema.sql   ★データベース定義（RLS・履歴・二重登録防止）
tests/                自動テスト
docs/                 手順書
```

データ構造（schema.sql）・集計（calc.js）・画面（views）・出力（csv.js）を分けているので、例えば「指定様式の出力」を追加するときは csv.js と views/other.js の出力画面だけを触れば済みます。

## デモ
`js/config.js` が空欄のまま開くと「デモモード」で起動します。画面上部に赤帯で「保存されません・本番利用不可」と表示され、データはメモリ上のみ（再読み込みで消える）です。
